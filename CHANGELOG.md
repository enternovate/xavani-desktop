# Changelog

All notable changes to Xavani Desktop are documented here.

## [0.3.0] - 2026-08-23 — Everyday Carry

### Added

- Persistent task pane with drag prioritisation.
- Outstanding-work reminders and desktop notifications.
- Profile switcher and expanded settings.
- Gemini CLI, OpenCode and generic-folder imports.
- Skills marketplace search, install and uninstall flows.
- Cron job creation.
- Studio file explorer, editor and live preview workspace.
- Two-way visual editing that maps preview changes back to source files.

### Changed

- Desktop and Xavani Agent version alignment moved to 0.3.0.
- Release links now point to exact versioned assets.
- Privacy documentation now discloses the anonymous GitHub update check.

## [0.2.0] - 2026-08-22 — CLI Parity

### Added

- Full command autocomplete and first-run setup wizard.
- Expanded settings for models, tools, MCP, profiles and display.
- Media visual editing and voice input.

Detailed notes: `docs/release-notes-0.2.0.md`.
